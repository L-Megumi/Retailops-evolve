## 已修复

1. AST 拒绝私有属性及属性提取、方法别名、Builtin 重绑定、默认参数和嵌套函数。Worker 清空宿主环境、关闭多余文件描述符、隔离工作目录；Linux 内核 seccomp 默认拒绝文件打开、网络、fork/exec 等系统调用，强制 CPU/内存等资源限制。失败即拒绝执行。
2. 可信 Metric Catalog 独立检查字段、整数类型、计数关系和计算结果；不接受模型自拟 Oracle。指标在激活前通过两组不同种子的验证，证据绑定代码、Spec 与 Verifier 摘要；执行时仍校验结果。未知 Verifier 或错误数据视图直接拒绝。去重/封顶转换也逐次对照独立业务逻辑，拒绝静默丢弃有效退款；只读指标不能冒充转换能力。
3. 插件声明 raw/effective 数据视图。去重和封顶只处理有效退款视图；重放率读取原始退款，组合后仍返回原输入的 3333 bps。
4. TaskContract 统一必需结果、必需转换和禁止操作；任务规划、CLI、插件路由共用该契约。否定操作优先，部分命中会补齐显式必需能力，缺失转换时停止执行。路由缓存绑定完整契约及能力定义。
5. CapabilityEvolver 通过统一 Agent/CLI 入口执行候选生成、错误反馈、准入、冻结审计、持久注册及复用；候选失败不修改正式注册表，模型调用有次数上限。支持三种可信指标定义，其中新能力是否能由真实模型生成，本轮未做模型实验。
6. 注册表通过文件锁、唯一临时文件、fsync 与版本冲突检测保护写入；进程内使用可重入锁，过期写入会回滚内存状态。路由缓存采用锁内增量合并，保留其他进程新增条目。
7. FastAPI 提供任务提交/查询/SSE Trace，Pydantic 限定请求格式，数据访问限制在指定 CSV 目录，外部绑定要求 Bearer Token。SQLite WAL 保存任务及事件，通过 CAS Claim 与租约心跳协调 Worker；失联任务保留为 interrupted，禁止盲目重放。提供非 root Docker 配置和已验证的服务依赖版本锁。

## 仍然成立的边界

- 自动演进仅限开发者提供独立定义与 Verifier 的受控指标；无法自动证明任意新业务算法正确。
- 规则任务提取有明确的语言覆盖范围；复杂任务可用模型规划或显式输出契约，低覆盖任务会拒绝执行。
- Linux seccomp 不是虚拟机，安全性仍依赖正确的内核和 Python 实现；本轮仅在 ljh3 的 Linux x86_64 验证。
- 中断恢复提供状态和证据，不声称跨进程崩溃的任意外部副作用 exactly-once。
- 新版本尚未进行完整端到端回归或真实模型效果验证。
